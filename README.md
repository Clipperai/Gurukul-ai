# 🚀 Gurukul AI

An AI-powered career growth platform built to help students and developers learn smarter, identify missing skills, and improve resumes with personalized AI guidance.

---

# ✨ Features

## 🛣️ Dynamic Roadmap Generator
Generate personalized learning roadmaps based on:
- Current skill level
- Career goals
- Tech stack
- Time availability

### Example:
- Frontend Developer Roadmap
- AI Engineer Roadmap
- Full Stack Developer Roadmap

---

## 📊 Skill Gap Analyzer
Analyze your current skills and compare them with industry requirements.

### It helps users:
- Find missing skills
- Discover weak areas
- Get improvement suggestions
- Understand job market expectations

### Example:
If a user wants to become an ML Engineer:
- Existing Skills → Python, HTML
- Missing Skills → TensorFlow, Statistics, APIs, SQL

---

## 📄 Resume Analyzer AI
Upload your resume and get:
- ATS score analysis
- Skill recommendations
- Resume improvement suggestions
- Missing keyword detection
- Professional feedback

### Supported Formats
- PDF

---

# 🧠 Why Gurukul AI?

Most students:
- Learn randomly
- Follow outdated roadmaps
- Don’t know industry requirements
- Build weak resumes

Gurukul AI solves this using AI-driven personalized guidance.
